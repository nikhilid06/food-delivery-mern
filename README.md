# 🍔 Food Delivery Web Application (MERN Stack)

A full-stack food delivery application built using MongoDB, Express.js, React.js, and Node.js.

## 🚀 Features
- **User Authentication:** Login and Registration system.
- **Menu & Cart:** Browse food items, add/remove items from cart, and track total cost.
- **Order Placement & Payments:** Integrated Stripe payment gateway for checkout.
- **Admin Panel:** Manage food items, track customer orders, and update order status.

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Payment Gateway:** Stripe
